🖥️ ComputerAgent - Test simple

Chaque bouton déclenche une action sur votre ordinateur

1 📺 Info écran
Récupère la taille de votre écran (largeur x hauteur).
→ Appelle /api/computer/screen
Cliquez sur le bouton
2 🚀 Ouvrir Notepad
Lance l'application Notepad sur votre ordinateur.
→ Appelle /api/computer/open-notepad
→ Python fait subprocess.Popen(['notepad.exe'])
Cliquez sur le bouton
3 ✍️ Écrire du texte
Tape du texte au clavier, comme si vous tapiez vous-même.
→ Appelle /api/computer/write-text
→ Python fait pyautogui.write(text)
Cliquez sur le bouton
4 ↵ Appuyer sur Entrée
Simule l'appui sur la touche Entrée.
→ Appelle /api/computer/press-enter
→ Python fait pyautogui.press('enter')
Cliquez sur le bouton
5 📸 Capture d'écran
Prend une photo de votre écran et l'enregistre.
→ Appelle /api/computer/screenshot
→ Python fait pyautogui.screenshot()
Cliquez sur le bouton
